* **Framework:** React Native (Expo)
* **Folder Structure:** Feature/Layer-based inside `/src` (`components/`, `screens/`, `services/`, etc.)
* **Naming Conventions:** 
  * `PascalCase` for Components and Screens (e.g., `CarDetails.tsx`)
  * `camelCase` for variables and functions (e.g., `calculateTotal()`)
